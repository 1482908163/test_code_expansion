# 第二轮迭代：面向尾部耗时的模型与误差约束分区

状态：代码与本地验证完成；尚未运行本版本的集群校准和性能评价。这里的 v3 是模型/特征格式版本，仍属于第二轮研究迭代，不表示已经完成第三批实验。

## 1. 从实测结果作出的决定

第二轮上传提交为 `445e6f49f33dbd3c8023476461688a905bc2b21f`，目录为 `strong_scaling_results/mesh_algorithms_20260907-132958`。完整数据口径和分析见 [校准归档](20260907_calibration.md)。其80次正式运行与16次预热全部完成，但只包含 baseline/sparse，没有采用新耗时模型的 balance/combined 性能评价。

已有证据支持以下判断：

- 8192进程的自然运行核心时间，baseline 为18.44763秒，sparse 为13.01814秒；完整面处理从6.61916秒降至0.75522秒。稀疏通信已经产生明显收益，本次不修改其协议。
- 8192进程局部体网格生成约占六个计算阶段总时间的91%；这是该规模的占比，不是所有规模均为91%。
- 八特征模型的跨规模平均误差有所改善，但2048/4096/8192真实最慢进程仍分别被低估26.66%/28.48%/25.95%。仅把预测最大值降低5%不能证明真实最慢进程会变快。
- 相同划分的局部体网格生成时间在 baseline/sparse 间高度相关，重复噪声较小。原因可能包含未观测的几何/网格器内部成本和稳定的节点差异；当前数据不能完全区分两者。
- 原采样只测量一种种子分区，无法检验改变分区之后的预测。重复运行同一个分区不会增加不同几何样本。

因此，本轮保持最多4轮粗单元修正，改进特征、训练样本与采用判据。集中式分区和分层稀疏交换仍待后续处理，不把程序细节优化当作论文创新。

## 2. 新增六个可随移动更新的特征

前八个特征保持原定义；新格式为 `mesh_phase_v3`，共14个特征、4个非负分阶段预测。新增特征只依赖已有粗四面体坐标与分区边界。

记外露粗面数为 B，面积总和为 A，粗四面体数为 E，体积总和为 V，`g=4^L`，平均间距体工作代理为 N。面/体形状惩罚分别为 `d_f=max(0,1/q_f-1)`、`d_e=max(0,1/q_e-1)`；质量定义沿用 [研究记录](../research_log.md)。

| 索引 | 特征 | 目的 |
|---:|---|---|
| 8 | `N * max(0, B*sum(a_f^2)/A^2 - 1)` | 面积变异，区分同均值但尺寸分散不同的边界 |
| 9 | `N * max(0, E*sum(v_e^2)/V^2 - 1)` | 粗单元体积变异 |
| 10 | `g * sum(d_f^2)` | 加重少量低质量边界面的影响 |
| 11 | `N * sum(v_e*d_e^2)/V` | 体积加权的粗四面体形状尾部 |
| 12 | `B*g * max(0, A^(3/2)/(6*sqrt(pi)*V)-1)` | 子域偏离紧凑形状的程度 |
| 13 | `B*g * clip(1.5*(tr(M^2)/A^2 - 1/3),0,1)` | 边界法向分布的各向异性 |

其中 `M=sum(a_f*n_f*n_f^T)`，n 为单位面法向。法向正负不影响外积；特征不随整体旋转改变。规则各向同性分布的指标接近0，法向高度集中时接近1。这不是曲率。

新增的面积平方和、体积平方和、形状二阶矩与法向张量都可以做加减更新，不需要每次候选移动重新生成细网格。针对性测试比较增量统计与全量重新计算。

这些仍然是待验证的粗几何代理。没有读取 CAD 曲率、材料接口细节或 Netgen 实际内部尺寸场。没有证据表明“特征由8变14”必然减少误差。

## 3. 训练目标和隔离方法

本轮校准使用3个 METIS 种子：`-1 17 41`。-1 保留原库默认行为；另外两个显式设置 `METIS_OPTION_SEED`。每个种子独立预热1次、正式3次，采用 sparse/natural。每个进程规模仍只有一个作业，作业内轮换种子与算法顺序。METIS 返回失败、网格程序失败或采集缺失的运行不进入训练。

不同种子的分区不保证生成相同细网格数量，因此按种子分组汇总，不能混成9次相同工作量的重复实验。训练器还检查各种子的特征多重集合确实不同，避免只把同一分区的标签置换当成新几何样本。这不能替代完整网格质量检查。

对每个 `(进程数, 种子, 进程号)`，按阶段取正式重复中位数。训练器要求每个进程至少两次、重复特征一致、所有种子/进程完整、分析异常为空，且输入、可执行文件、网格参数、线程数、特征格式和源版本一致。

训练四个非负岭回归阶段模型：

1. 各 `(进程数, 种子)` 组总权重相同。
2. 每组训练样本中，总计算时间最慢10%的样本权重为其他样本的4倍，再在组内归一化。四阶段使用同一套权重，目标是更重视核心计算尾部。
3. 加权均方根缩放特征，正则系数保持 `1e-4`；尾部比例、倍数没有根据本轮评价结果调参。
4. 对目标规模 P，先排除其整个数据文件，不读取其特征范围、耗时或误差；再在剩余数据中分别做整规模留出、整种子留出。
5. 每个留出组同时报告新模型、原八特征非加权模型、常数加 N 的控制模型：阶段/总计算 WAPE、实际最慢进程误差、预测最大值误差、最慢1%召回率。

种子留出中包含多个进程规模：最慢1%召回先在每个 `(规模,种子)` 内计算再等权平均，最慢进程误差报告各组绝对值最差者，完整组别明细保存到 JSON。不能用跨规模混在一起的最高耗时进程掩盖8192组内部的排序失败。报告中的 WAPE 则明确为全部留出样本的总绝对误差除以总实测时间。

原八特征控制与新模型的差异同时包含特征及尾部权重；当前报告不能单独证明各自贡献。若新模型整体有效，应追加去掉尾部权重、去掉新增特征的独立消融，再论证机制。

跨种子留出比重复同一种子更严格，但仍不是直接验证每一步粗单元移动的反事实耗时。本批同一几何；跨几何验证仍未实现。

## 4. 从预测误差到采用判据

用训练规模内部的整组留出预测，计算总计算时间的双侧最坏相对残差，分母均为预测值：

`e_over  = max(0, max((predicted-actual)/predicted))`

`e_under = max(0, max((actual-predicted)/predicted))`

定义经验范围：`L_i=max(0,1-e_over)*predicted_i`，`U_i=(1+e_under)*predicted_i`。这些是**经验误差包络，不是置信区间，也不保证覆盖所有新分区**。它们可能过于保守，也可能在新分布上失效。

移动搜索继续要求邻接迁移、非空、供给分区不被拆开、受影响边界局部流形有效、受影响双方预测最大值不增加且平方和下降。种子或候选特征超出训练最小/最大范围时，不使用该预测进行修正；处于这个范围内同样不能证明属于训练分布。

最终候选必须同时满足：

`G_lower = max_i(L_seed_i) - max_i(U_candidate_i) - t_correction`

`G_lower > max(MIN_GAIN_SECONDS, MIN_GAIN_FRACTION * max_i(predicted_seed_i))`

以及原有切分面、总依赖闭包记录数、单进程最大闭包记录数预算。默认门槛0.35秒和5%保留，**新增的是显式误差与实测修正耗时，不是单纯调大阈值**。

`t_correction` 从公共种子统计完成之后开始，包含种子复制、额外预测、依赖闭包计算、拓扑准备与移动搜索，扣到采用判定时刻。`correction_seconds` 最终记录到函数返回前，可能还包含微小的判定/回退成本，故与 `G_lower` 中采用时刻的时间存在微小差别。METIS、公共几何统计、分发、所有拒绝和回退开销仍计入原核心计时。

非负模型的常数项 b 给出所有非空候选预测值的下界。若 `max(L_seed)-(1+e_under)*b` 连基本收益门槛也无法跨过，可在构造闭包和移动搜索前直接跳过。否则用 `SEARCH_SECONDS=0.35` 限制继续尝试移动的时间，预算到达时评估当前候选。计时从修正开始，包含前置闭包/拓扑准备；它是软预算，不能中断一次进行中的闭包构造、排序或拓扑检查，最终开销可能超过0.35秒。

没有把依赖记录数换算成已校准网络秒数，采用判据仍然是“经验计算收益减修正成本，加通信依赖硬约束”。通信变化、上游完成差与其他未预测阶段，必须由真实核心总时间来裁决。

## 5. 用第二轮旧数据检验设计是否必要

对旧八特征数据复现原非加权拟合，仅在训练规模内部计算上述残差；目标规模只用于事后诊断种子预测。结果见 [可复核数值](20260907_risk_screen.json)。这不是新14特征模型的实验结果。

| 目标进程数 | 高估包络 | 低估包络 | 种子耗时经验下界/s | 候选上界的常数项下限/s | 搜索前判定 |
|---:|---:|---:|---:|---:|---|
| 1024 | 63.31% | 44.55% | 5.561 | 5.669 | 不足以支持修正 |
| 2048 | 63.72% | 46.73% | 3.937 | 6.019 | 不足以支持修正 |
| 4096 | 66.29% | 42.28% | 2.686 | 5.660 | 不足以支持修正 |
| 8192 | 37.44% | 37.52% | 4.647 | 6.383 | 不足以支持修正 |

旧模型在四个规模均无法通过这个必要条件。这个结果说明当前预测误差不足以支持有把握的局部修正，也说明只加入保守门槛很可能全部回退；**不能把“回退到 sparse”宣称为负载均衡成功**。因此本轮也扩充分区样本和几何特征。新模型若仍不能缩小误差，应进一步调查网格器内部阶段或采用不同任务分解方法，不能通过放宽误差标准制造成功结果。

复核方法：在仓库根目录用 `runpy.run_path('strong_scaling/fit_cost_model.py')` 载入模块，调用 `train(Path(旧校准根目录), P, 3, 3)`；manifest 的 `residual_envelope` 仅来自其他规模的内部留出。用模型预测 P 的分区，取最大值 m；表中两列时间分别为 `m*(1-e_over)`、`sum(各阶段常数项)*(1+e_under)`。旧格式训练仅供追溯，统一评价入口拒绝将其作为 v3 模型。

## 6. 如何运行及判读

统一入口仍是 `bash strong_scaling/run_experiments.sh`，无需在命令行拼接参数。更新代码后先用原构建流程重新编译。

| 配置 | 本轮校准默认 | 随后的评价默认 |
|---|---|---|
| `EXPERIMENT_STAGE` | `calibration` | `evaluation` |
| `EXPERIMENT_PRESET` | `production` | `production` |
| MPI进程数 | 1024、2048、4096、8192 | 同左 |
| 节点数（每节点16进程） | 64、128、256、512 | 同左 |
| 表面/体细化 | L=R=3 | 同左 |
| 算法 | sparse | baseline、balance、sparse、combined |
| 计时 | natural | natural、split |
| 种子 | -1、17、41 | -1 |
| 每组预热/正式 | 1/3 | 1/5 |
| 全部正式/预热次数 | 36/12 | 160/32 |
| 作业数 | 4 | 4 |

需要先核对新种子能否生成完整网格时，在同一配置区将 `EXPERIMENT_PRESET` 改为 `pilot`：16/32/64进程、1/2/4节点、L=R=1，并逐种子执行稀疏面闭包核对。pilot 的 L/R 与 production 不同，其样本不能用于正式规模训练。

新校准完成后，只在同一配置区将 `EXPERIMENT_STAGE` 改成 `evaluation`，`CALIBRATION_ROOT` 填新结果目录，保持其余设置一致再运行入口。旧批缺少6个新特征及不同种子的样本，不能补造；评价会在提交作业前拒绝这种混用。二进制哈希也必须与校准一致。

优先查看每个 `p*/RESULT_SUMMARY.txt`。它按种子列出结果；评价时增加采用比例、跳过搜索次数和拒绝原因次数；位标志不能取中位数后再解码，应看计数：1=名义收益不足，2/4=总/最大闭包超预算，8=无移动，16=误差或净收益不足，32=超出特征范围。预算耗尽另看 `search_timed_out`。跳过时没有构造闭包，其零值表示未测，不表示通信依赖为零。

`analysis/summary.csv` 新增同种子的 `speedup_vs_sparse`，用于判断 combined 相对 sparse 的独立收益。`model_samples.csv.gz` 保留新特征、种子和 `processor_name`，后者在核心计时之外采集，仅用于后续残差归因，不输入模型。源版本在登录节点获取并传入作业，避免计算节点缺少 git 导致原来的空字段。

成功运行的数据清理、无损压缩、失败保留与断点续跑保持原机制。只扩展现有两个测试文件，没有新增测试目录。使用新的结果目录；历史实验和原采集分支不修改。

采用成功标准：同一规模/种子、相同计时口径下，combined 相对 sparse 的**完整核心时间**有可重复净下降，计算尾部与等待得到解释，且分区成本、实际网格单元数、边界和质量可接受。若全部回退、只减少代理值、或核心时间不变，则均衡方法尚未成功。不同进程规模细单元总量仍可能变化，不能直接当固定工作量的严格强扩展。

## 7. 验证范围与研究定位

本地通过：100组粗分区合成检查，新增统计增量/全量一致、误差拒绝、超范围提前跳过、软预算路径、模型解析；脚本检查包含多种子分组、预热与断点续跑、跨规模/种子留出、目标数据损坏仍被排除、旧样本阻止评价、新样本导出、负净收益保留和统一入口提交模拟。既有18组稀疏数据模拟、百亿全局编号合成测试继续通过。

MPI 组件编译并通过单进程编号和 natural/split 面交换检查。本地传输仅使用 `UCX_TLS=self`，环境仍报告网络接口权限告警；这不能证明多进程网络通信正确。主程序/分区适配器使用官方 METIS 头文件的32位和64位 idx_t 两种配置均通过语法检查；定制 Netgen/OpenCascade 部分使用声明桩，不能代替集群链接、完整网格与质量验证。

METIS 的种子参数属于已有库能力，见 [METIS 手册](https://glaros.dtc.umn.edu/gkhome/fetch/sw/metis/manual.pdf) 和 [官方接口](https://github.com/KarypisLab/METIS/blob/master/include/metis.h)。本次核对的接口文件 blob 为 `ab475fe6f943c08fe7c064eb120b6eb09261f1ff`。非负回归、尾部加权、误差包络、最小化最大值均不能单独称为原创。

可研究的组合贡献是：分区边界的尺寸/形状如何影响局部重网格耗时，以及如何把预测可靠程度、拓扑依赖和修正成本共同纳入分区采用决策。其有效性仍需新实验和消融证明。计算/通信/迁移代价联合考虑已有 [超图重分区研究](https://doi.org/10.1016/j.jpdc.2009.04.011)；本实现不是全超图优化，也没有采用其动态网格迁移机制。若静态几何模型继续失效，可研究利用实际等待反馈的任务迁移，参考 [Samfass 等人的反应式迁移研究](https://arxiv.org/abs/1909.06096)，但那需要先拆分独立网格任务，不是简单替换 MPI 等待函数。

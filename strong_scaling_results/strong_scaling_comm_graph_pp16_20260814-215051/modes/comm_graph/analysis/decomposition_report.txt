Partition and Load Diagnostics (分区与负载诊断)
================================================================================================================================================================================
当前实现固定采用 numParts = MPI_COMM_WORLD size：网格分区数等于 MPI 进程总数，每个 rank 对应一个 METIS 分区；它不等于计算节点数，也不是独立实验参数。
各 P 默认使用 repeat 2+ 的 warm（热缓存）样本中位数；若没有 warm 样本，才退回使用当前可用重复。decomposition_runs.csv 仍保留全部重复。
VertexCopy = 邻接交换前所有 rank 的局部点数之和 / 唯一归属点数；VolumeCopy = 邻接交换后 / 交换前的体单元总数；Load M/A = rank 局部体单元最大值 / 平均值。
相关系数 r(Load,Mesh) > 0 表示体单元较多的 rank 计算更久；r(Load,Wait) < 0 表示体单元较少、较早到达的 rank 等待更久。两者同时出现才是‘负载不均衡转化为同步等待’的直接证据。
